# P1 – Project Folder and Terminal Navigation

## Objective
To understand basic terminal commands and learn how to navigate between folders in a project.

## Commands Practised

| Command -- Purpose |
| `pwd` -- Displays the current working directory |
| `ls` -- Lists files and folders |
| `cd` -- Changes the current directory |
| `mkdir` -- Creates a new directory |
| `touch` -- Creates a new file |
| `cd ..` -- Moves one directory back |

## Result
Successfully created the project folder structure and practised navigating between directories using terminal commands.
