# P4 – GitHub README and Version Tags

## Aim
To understand how to document a GitHub repository using a README file and manage project versions using Git tags.

## Objective
To create and update a README file containing project information and use Git tags to mark a specific version of the project.

## Procedure

1. Opened the main repository README.md file.
2. Added the project title and description.
3. Documented all three modules and their practicals.
4. Added information about the technologies used.
5. Saved the README file.
6. Created a Git version tag to identify the project version.

## Git Commands Used

| Command -- Description |
| `git tag` -- Lists available tags |
| `git tag v1.0` -- Creates a version tag |
| `git push origin v1.0` -- Pushes the tag to GitHub |

## Result
Successfully documented the GitHub repository using a README file and created a version tag to mark the project version.
