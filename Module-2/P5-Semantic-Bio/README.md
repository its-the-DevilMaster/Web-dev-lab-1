# P5 – Semantic Bio Page

## Aim
To create a personal biography webpage using semantic HTML elements.

## HTML Elements Used
- `<header>` – Displays the page heading.
- `<nav>` – Provides navigation links.
- `<main>` – Contains the main content.
- `<section>` – Divides content into sections.
- `<footer>` – Displays footer information.

## CSS
External CSS is used to style the webpage, including the header, navigation bar, content sections and footer.

## Result
A structured and styled biography webpage was created using semantic HTML and CSS.
