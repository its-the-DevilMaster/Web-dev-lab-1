
# P8 - CSS Positioning

## Aim
To understand and demonstrate different CSS positioning properties.

## Positioning Properties Used
1. Static
2. Relative
3. Absolute
4. Fixed
5. Sticky

## Other CSS Properties
- top, bottom, left and right
- z-index
- position

## Concepts
- Static is the default positioning.
- Relative positions an element relative to its normal position.
- Absolute positions an element relative to its nearest positioned ancestor.
- Fixed keeps an element in a fixed viewport position.
- Sticky switches between normal and fixed-like positioning while scrolling.
- Z-index controls the stacking order of positioned elements.
