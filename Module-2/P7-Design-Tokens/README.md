
# P7 - CSS Design Tokens

## Aim
To create a reusable CSS design system using CSS custom properties (variables).

## Design Tokens Used

### 1. Color Tokens
- Primary color
- Secondary color
- Accent color
- Background color
- Text color

### 2. Typography Tokens
- Font family
- Heading size
- Body text size

### 3. Spacing Tokens
- Small spacing
- Medium spacing
- Large spacing

### 4. Border Tokens
- Border radius

## CSS Concepts Used
- :root selector
- CSS custom properties
- var() function
- Reusable styling values

## Result
A webpage demonstrating reusable CSS design tokens was successfully created.
