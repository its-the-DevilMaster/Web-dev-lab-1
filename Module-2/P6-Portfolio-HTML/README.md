# P6 - Personal Portfolio Website

## Aim
To create a personal portfolio webpage using HTML.

## Sections Included
- Header
- Navigation bar
- About Me
- Education
- Skills
- Projects
- Contact
- Footer

## HTML Elements Used
- `<header>`
- `<nav>`
- `<main>`
- `<section>`
- `<article>`
- `<footer>`

## CSS Styling
CSS is used to style the webpage, including its background, navigation bar, content sections and footer.

## Result
A personal portfolio webpage was successfully created using HTML and CSS.
