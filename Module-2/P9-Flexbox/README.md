
# P9 - CSS Flexbox

## Aim
To create flexible webpage layouts using CSS Flexbox.

## Flexbox Properties Used
1. display: flex
2. flex-direction
3. justify-content
4. align-items
5. flex-wrap
6. gap
7. flex-grow

## Concepts
- Flexbox is a one-dimensional layout system.
- flex-direction controls the direction of items.
- justify-content aligns items along the main axis.
- align-items aligns items along the cross axis.
- flex-wrap allows items to move to another line.
- gap creates space between items.
- flex-grow controls how available space is distributed.

## Result
A webpage demonstrating different Flexbox properties was successfully created.
