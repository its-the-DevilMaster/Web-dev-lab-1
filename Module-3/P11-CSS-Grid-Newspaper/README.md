
# P11 - CSS Grid Newspaper Layout

## Aim
To create a newspaper-style webpage using CSS Grid.

## CSS Grid Properties Used
1. display: grid
2. grid-template-columns
3. grid-template-rows
4. grid-column
5. grid-row
6. gap
7. Media queries

## Concepts
- CSS Grid is a two-dimensional layout system.
- grid-template-columns defines the column structure.
- grid-template-rows defines the row structure.
- grid-column controls an item's column placement.
- grid-row controls an item's row placement.
- gap creates space between grid items.
- Media queries make the layout responsive.

## Result
A responsive newspaper-style webpage was successfully created using CSS Grid.
