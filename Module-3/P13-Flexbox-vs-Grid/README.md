# P13 – Flexbox vs CSS Grid

## Aim
To understand and compare CSS Flexbox and CSS Grid layouts.

## Flexbox
Flexbox is a one-dimensional layout system.

Properties used:
- display: flex
- justify-content
- align-items
- flex-wrap
- gap

## CSS Grid
CSS Grid is a two-dimensional layout system.

Properties used:
- display: grid
- grid-template-columns
- gap

## Comparison
- Flexbox is suitable for arranging items in a row or column.
- Grid is suitable for arranging items in rows and columns.
- Flexbox is useful for navigation bars and components.
- Grid is useful for complete webpage layouts.

## Responsive Design
A media query is used to adjust the Grid layout on smaller screens.
