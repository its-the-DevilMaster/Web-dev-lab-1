
# P12 - Advanced CSS Grid

## Aim
To understand and implement advanced CSS Grid layout techniques.

## Properties Used
1. grid-template-areas
2. repeat()
3. minmax()
4. auto-fit
5. grid-auto-rows
6. Nested grids
7. Media queries

## Concepts
- grid-template-areas creates named layout regions.
- repeat() repeats column or row definitions.
- minmax() defines minimum and maximum track sizes.
- auto-fit adjusts the number of columns to available space.
- grid-auto-rows controls automatically created rows.
- Nested grids allow a grid container inside another grid.

A responsive webpage demonstrating advanced CSS Grid properties was successfully created.
