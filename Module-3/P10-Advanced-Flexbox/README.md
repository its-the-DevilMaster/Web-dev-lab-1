
# P10 - Advanced Flexbox

## Aim
To understand and demonstrate advanced CSS Flexbox properties.

## Properties Used
1. flex-grow
2. flex-shrink
3. flex-basis
4. flex shorthand
5. order
6. align-self

## Concepts
- flex-grow determines how extra space is distributed.
- flex-shrink determines how items shrink when space is limited.
- flex-basis defines the initial size of a flex item.
- flex shorthand combines grow, shrink and basis.
- order changes the visual order of flex items.
- align-self controls the alignment of an individual flex item.
- Media queries help create responsive layouts.
